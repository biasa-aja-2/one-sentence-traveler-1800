One sentence, at most 200 characters, explaining the modern internet to someone arriving from 1800 — built only from things a person of that year already knows: a road, a house, a library, a post office, a letter, ink. No word coined after their time, no list of features, just one picture they can hold in their head: a letter that arrives before its ink is dry.

> It is one road joining houses across the earth to a single vast library and post office, where any letter you write arrives before the ink is dry.

## Run it

```sh
python3 main.py
```

The program self-checks the kit's gates (UTF-8, 1–200 characters, one line, exactly one sentence, not whitespace-only) and refuses to write if any gate fails, then writes the sentence to `/output/entry.txt` and verifies it by reading it back.
